Three Next.js App Router route segments under `src/app/`: the root `page.tsx` serves as the landing page with six stacked sections (hero, value proposition, learning pathway, safety principles, articles entry, community/contact entry), while `about/page.tsx` and `contact/page.tsx` are dedicated informational routes. Each page is a server component that exports a `Metadata` object for SEO/OpenGraph and a default React function component. All three pages compose shared UI primitives from the project's design system (`@/components/layout/container`, `@/components/ui/badge`, `@/components/ui/card`) rather than defining their own layout shell, keeping this module purely presentational. The home page additionally pulls live data via `getPublishedArticles()` from `@/lib/articles` to render recent article previews, making it the only page in scope with a data dependency; about and contact are fully static content.
