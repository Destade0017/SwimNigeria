Two parallel content verticals under Next.js App Router: `src/app/articles` (list + `[slug]` detail) and `src/app/courses` (catalog + `[courseSlug]` syllabus + nested `[courseSlug]/lessons/[lessonSlug]` preview). Each route is a Server Component that imports data accessors (`getArticlesByCategory`, `getArticleBySlug`, `getPublishedArticles`, `getRelatedArticles`, `getFilteredCourses`, `getCourseBySlug`, `getPreviewLesson`, `getAdjacentPreviewLessons`, `getSafeVideoEmbed`) from `@/lib/articles` and `@/lib/courses`. Static page generation uses `generateStaticParams` over published items, while `generateMetadata` builds SEO titles/descriptions per resource. Routing is purely URL-driven with no client state; filtering on list pages is query-string based (`?category=...`, `?difficulty=...`). All UI is composed from shared primitives in `@/components/layout/container`, `@/components/ui/badge`, `@/components/ui/card`, and `@/components/ui/button`; there is no internal routing or API layer inside this module — it depends only on the lib layer and shared components.
