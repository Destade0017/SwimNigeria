Three sub-packages with a clear dependency direction: `ui/` holds atomic, stateless primitives (Button, Card, Dialog, Badge, Input, Textarea, Skeleton) that depend only on `@/lib/utils` (`cn`); `layout/` composes those primitives into page chrome (Container, SiteHeader, MobileNav, SiteFooter) and is consumed by pages; `auth/` sits above both, composing `ui/Button` with server actions from `@/app/login/actions`. All components are function components using `forwardRef`; variants/sizes are expressed via typed string unions and style lookup tables rather than CSS-in-JS. Client-only behavior is opt-in via the `'use client'` directive at the top of interactive files (logout-button, mobile-nav).
