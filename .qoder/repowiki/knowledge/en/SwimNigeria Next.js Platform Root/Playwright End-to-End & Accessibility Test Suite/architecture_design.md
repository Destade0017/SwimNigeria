Flat collection of Playwright spec files under `e2e/`, one per feature area (smoke, login, register, articles, courses, dialog, layout, about-contact). Each file is an independent test suite using `test.describe` to group related scenarios for a single route or interaction surface. Tests drive the live frontend via `page.goto()` against relative URLs (`/`, `/login`, `/articles`, `/courses`, `/test-dialog`) and assert behavior through Playwright locators (`getByRole`, `getByText`, `locator('#id')`). There is no shared page-object layer or fixtures — each spec imports only `@playwright/test` and, where needed, `@axe-core/playwright` for automated WCAG scans. Dependency direction is one-way: specs depend on the running application; there are no internal helpers or cross-spec modules.
