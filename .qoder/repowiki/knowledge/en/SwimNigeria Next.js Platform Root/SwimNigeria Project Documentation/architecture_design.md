This module is a flat collection of Markdown documents that define the SwimNigeria project's scope and technical blueprint rather than executable code. Key documents form a layered reference: `PROJECT_BRIEF.md` sets vision, audience, constraints (₦0 budget, low-bandwidth mobile-first), and MVP scope; `SYSTEM_ARCHITECTURE.md` specifies the four-layer stack (Next.js App Router + RSC frontend, Server Actions/Route Handlers runtime, Supabase Postgres with RLS, zero-cost third-party services like YouTube embeds and Resend) and includes Mermaid sequence diagrams for enrolment and certificate issuance; `DATABASE_DESIGN.md`, `DESIGN_SYSTEM.md`, `SECURITY.md`, `TESTING_STRATEGY.md`, `DEPLOYMENT_AND_OPERATIONS.md`, and `IMPLEMENTATION_ROADMAP.md` flesh out each subsystem; `TECHNOLOGY_EVALUATION.md` records the option-vs-decision rationale for every major stack choice; `DECISION_LOG.md` tracks decisions over time; `KNOWN_LIMITATIONS.md`, `PRODUCT_REQUIREMENTS.md`, `AGENT_SKILLS_REGISTER.md`, `CODING_STANDARDS.md`, and `DEVELOPMENT_RULES.md` provide cross-cutting engineering guardrails. Dependency direction is one-way: all technical docs reference the brief and system architecture as the single source of truth.
