The root is a standard Next.js 16 application (Next 16.4.3 / React 19) whose runtime surface is the `app_pages` module (`src/app`) providing the App Router entry points; it depends on `components` for reusable UI/layout primitives and on `lib` for the Supabase client factories, Zod auth schemas, constants, and in-memory content registries. Cross-cutting configuration lives at this level: `next.config.ts` enables Strict Mode and whitelists dev origins, `tsconfig.json` maps `@/*` to `./src/*` with strict TS settings consumed by every child, and `postcss.config.mjs` wires Tailwind v4 via `@tailwindcss/postcss`. Two independent test layers share the same source tree — `unit_tests` uses Vitest with jsdom and `@testing-library/react`, while `e2e_tests` use Playwright with `@axe-core/playwright` for WCAG AA checks against the running app. The `docs` module is documentation-only and not part of the build.
