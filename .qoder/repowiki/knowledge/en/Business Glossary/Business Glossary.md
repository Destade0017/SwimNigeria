### SwimNigeria
- Definition：The project's product name: a digital aquatic education platform aimed at reducing drowning incidents in Nigeria by delivering structured swimming curricula, water safety guidelines, self-paced beginner courses, and verifiable digital certifications.

### Phase 1
- Definition：The completed initial milestone: Next.js 16 + TypeScript scaffolding, Tailwind v4 design tokens, ESLint/Prettier tooling, Vitest + React Testing Library unit/component tests, Playwright E2E smoke tests, and axe-core WCAG 2.1 AA accessibility audits. No business features, course data, mock learner records, or database migrations were introduced.

### Phase 2
- Definition：The next milestone after Phase 1: building reusable accessible UI primitives (Button, Input, Card, Badge, Skeleton), layout containers, and responsive navigation header/footer based on `docs/DESIGN_SYSTEM.md`.

### Phase 5
- Definition：A future milestone targeting production-grade authentication using PostgreSQL and Supabase Auth with SSR HttpOnly cookies.

### quality gates
- Definition：The mandatory pre-submit/pre-merge verification pipeline defined in the README: format check, Prettier auto-fix, TypeScript strict typecheck, ESLint 9 linting, Vitest unit/component tests, Playwright E2E smoke tests, production build, and production server start.
